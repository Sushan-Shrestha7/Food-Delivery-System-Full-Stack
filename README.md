# 🍽️ UGRACHANDI
### Food Delivery System

**A Modern Approach to Online Food Ordering**

A full-stack web application designed to simplify online food ordering, secure payment processing, and order management through a modern, user-friendly interface.

🍔 Browse Food · 🛒 Manage Cart · 📦 Place Orders

---

### 🛠️ Technology Stack

⚛️ **React** · 🚀 **NestJS** · 🐘 **PostgreSQL** · 🔗 **TypeORM**

### ✨ Key Features

- 🍕 Browse and explore food products
- 🛒 Add, update, and remove cart items
- 📦 Place and manage food orders
- 💳 Online payment integration
- ⏱️ Cancel orders within a specified time limit
- 🚚 Delivery personnel management
- 🔌 RESTful APIs with Swagger documentation
- 🗄️ Structured relational database management

---
